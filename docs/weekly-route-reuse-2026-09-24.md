# 每周课表与历史路线复用

后续调整：根据用户最新要求，新建路线页已移除“最近发布”区块、重试入口及发布成功后的历史快捷提示，同时停用该页面的历史查询和本地快捷缓存写入。当前入口只保留每周固定模板；下文关于历史复用的内容记录之前的实现与验证，不再代表当前界面。未删除云端历史行程或研究数据。

本轮修正司机新建路线页的快捷填写，不改变云端模板结构或自动发布行程。

- 每周模板优先展示，卡片包含星期、时刻、路线和本次将填写的日期；模板管理按周一到周日、同日时刻排序。
- 点击模板始终选择下一次可用的指定星期与时刻，覆盖表单原日期；用户仍可自行调整。
- 历史复用从原行程日期加七个日历日开始。若已过期，按整周推进；原行程在未来时仍取其下一周，避免重复同一次出行。
- 保持纽约时间，提前至少十五分钟，限定三十天发布窗口。春季不存在的时刻跳到下一周的同一星期，不改为次日。
- 同路线、同星期、同时间跨周合并；不同星期分别保留。旧缓存补读一次实际行程日期，此后继续每日缓存；离线且星期未知时留空日期，不推测。
- 保留路线价格、座位、备注及司机资料披露设置；所有快捷操作仅填写表单。
