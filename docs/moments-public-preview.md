# 朋友圈公开预览

朋友圈单页模式（场景值 `1154`）没有常规小程序登录态，不能在页面间跳转。原页面直接调用要求 `auth != null` 的云函数，会收到 `-501023 permission denied`。

本次复用现有 `marketApi`，云函数总数仍为 20。没有独立的 `publicPreview` 云函数。

## 使用体验

- 分享二手、转租、拼车或求车页面后，在朋友圈内读取公开列表、展开详情并返回列表。
- 已过期、已关闭、已删除或不存在的记录不展示详情。
- 联系、报名、发布等操作仍在完整小程序内进行，使用微信底部的“前往小程序”入口和现有登录、资料完善流程。
- 账户、编辑、消息等页面在单页模式下只显示服务介绍。
- 从“我的”详情或商品页分享时，进入完整小程序后转到对应公开详情或卖家商品页，避免进入观看者自己的管理页面。

## 云端权限

部署带有身份校验的新 `marketApi` 后，云函数调用规则为：

```json
{
  "*": { "invoke": "auth != null" },
  "marketApi": { "invoke": true }
}
```

环境已有 `NONLOGIN: ENABLE`，无需修改登录配置。其他云函数、数据库和存储权限均保持原规则。

匿名访问进入 `marketApi` 后，只允许 `action: "publicPreview"`。所有原操作统一要求服务端 `cloud.getWXContext().OPENID` 非空，再执行原有业务鉴权；传入的 `event.OPENID`、`event.auth` 等不能作为身份。

公开预览请求使用固定子操作 `marketList`、`marketDetail`、`tripList`、`tripDetail`。客户端不能指定集合、投影字段或数据库查询对象。后端限制分页与扫描范围，不执行创建、更新、计数、报名或状态同步。

响应仅包含 `id`、`kind`、`title`、`description`、`priceText`、`regionText`、`timeText`、`availabilityText`、`images`、`tags`。结构化联系人、用户身份、成员、支付和精确位置字段不返回。商品文案另外清理已知联系人、地址和明显联系方式；自由文本和发布图片不是人工审核后的材料，不能把这些处理视为内容审核保证。

图片仅从当前环境商品记录引用的指定目录解析临时 HTTPS 地址。链接在请求时生成，不写入代码或长期文档；存储规则不放开。

## 前端隔离

`utils/timeline.js` 只从 App 启动/前台场景判断模式，页面查询参数不能伪造运行场景。全部已注册页面采用统一渲染入口：单页模式挂载 `timeline-preview`，正常模式才挂载原页面组件并执行原生命周期。

单页模式停止原页面私有请求及推荐关系统计。浏览详情在同一组件中切换，不调用单页模式不支持的页面导航或登录 API。原始分享参数保留到进入完整小程序后；`timelineShare=1` 用于将私有分享来源映射到公开页面。

## 验证与发布

本地回归测试：

```sh
node --test tests/*.test.cjs
```

覆盖匿名鉴权、数据投影和脱敏、有效期、列表筛选、分页、图片路径、分享来源映射、生命周期恢复、请求竞态及错误展示。开发者工具可用 `simulator_open_page --scene 1154` 验证单页模式，完成后用 `--scene 1001` 检查正常页面。模拟器验证不能代替正式版本的 iOS/Android 朋友圈实机验收。

发布顺序：备份当前云端代码/配置/规则 → 部署现有 `marketApi` → 放开该函数的调用规则 → 验证公开读取及原操作鉴权 → 通过正常审核流程发布小程序前端。仅部署云函数不会修复仍运行旧前端的已发布版本。

如需回滚，先将函数规则恢复为备份中的 `auth != null`，再恢复旧 `marketApi` 代码与配置。旧代码没有统一匿名入口校验，不能在开放调用规则下直接恢复。

官方说明：[朋友圈单页模式](https://developers.weixin.qq.com/miniprogram/dev/framework/open-ability/share-timeline.html)、[云函数安全规则](https://docs.cloudbase.net/cloud-function/security-rules)。
